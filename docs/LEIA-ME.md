# Página de apresentação e download

A página está em `docs/index.html` e foi preparada para publicação através do GitHub Pages.

Para a publicar: abrir **Settings → Pages** no repositório, escolher **Deploy from a branch**, selecionar a branch `main` e a pasta `/docs`, e guardar. O endereço será `https://bombeiropt.github.io/Lista-Inteligente/`.
